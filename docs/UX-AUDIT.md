# UX audit — ตอบไว (2026-10-15, ก่อนยกเครื่องรอบ 2)

ตรวจจากภาพจอจริง 1440×900 และ 390×844 (Playwright) — สิ่งที่ทำให้ยังดู "เป็นต้นแบบ" ไม่ใช่ "ผลิตภัณฑ์"

## โครง / การนำทาง
1. **ไม่มีหน้าแรกของร้าน** — เข้าร้านแล้วตกไปกล่องแชททันที ไม่รู้ว่าวันนี้มีกี่ราย รอนานแค่ไหน บอทช่วยไปเท่าไหร่
2. **ไม่มีเช็กลิสต์ตั้งค่า** — ร้านใหม่ไม่รู้ว่าต้องทำอะไรต่อ (เชื่อมช่องทาง → แก้บอท → ตั้งกฎ → ลองทัก)
3. **แถบซ้ายบาง ป้าย 11px** ไอคอนเหมือนกันหมด แบรนด์จาง ไม่มีที่สลับร้าน/สถานะออนไลน์/แจ้งเตือน
4. **ไม่มีค้นหารวม / Ctrl+K** — ไปหน้าไหนต้องคลิกเมนู
5. หน้าเก่า (Facebook/บรอดแคสต์/สถิติ) ยังเป็นการ์ดเงาแบบเดิม สีเขียวคนละเฉด → ไม่เป็นระบบเดียวกัน

## กล่องแชท
6. **ไม่มีแจ้งเตือน** — ไม่มีเสียง ไม่มี desktop notification ไม่มีตัวเลขบนแท็บ → แอดมินพลาดลูกค้าที่รอ
7. ไม่มีแท็ก/ป้ายบทสนทนา, ไม่มีคีย์ลัด, ไม่มีสถานะออนไลน์ของแอดมิน
8. รายการแชทไม่บอกช่องทางเป็นคำ (มีแค่จุดสี) — ร้านที่ใช้หลายช่องทางแยกยาก
9. ใบรับเรื่องว่างเมื่อยังไม่มีข้อมูล — ควรมีประวัติ/แท็ก/โน้ต

## สร้างบอท
10. **ไม่มีเทมเพลตตามประเภทธุรกิจ** — "สร้างบอทใหม่" ได้หน้าว่างที่มีแค่จุดเริ่ม
11. ซูมพอดีจอแล้วตัวหนังสือใน node เล็กมาก (fitView maxZoom 1 แต่จอกว้างทำให้ ~0.6)

## เริ่มใช้งาน
12. สมัครเสร็จ → หน้ารายการร้านว่าง → สร้างร้าน → หน้า "ช่องทาง" ยาวทั้งหน้า ไม่มีลำดับขั้นให้ทำ
